# Politika kayıtları — kanıt etiketleri

Bu ortam resmî Google/YouTube sayfalarını açamıyor (bkz. `docs/research/2026-10-03-environment-capabilities.md`). Her kayıt şu etiketlerden birini taşır:

| Etiket | Anlamı |
|---|---|
| `verified-primary` | Resmî kaynak bu ortamdan doğrudan okundu (tarih + URL). |
| `chatgpt-verified` | **ChatGPT tarafından resmî kaynaktan doğrulandı; bu ortamdan doğrudan erişilemedi.** Kullanıcı 2026-10-03'te iletti. |
| `secondary` | Yalnızca ikincil kaynak (WebSearch özeti, blog). Karar dayanağı olarak tek başına kullanılmaz. |
| `unverified` | Doğrulanmadı; "doğrulanmış" sayılmaz, STATUS → Açık doğrulamalar listesinde. |

Dosyalar: `ypp-eligibility.md`, `monetization-and-inauthentic-content.md`, `synthetic-content-disclosure.md`, `production-gate.md`.
