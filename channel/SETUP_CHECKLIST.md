# Kanal kurulum listesi (kanal sahibi, ~20 dakika, bir kez)

Hesap sahibinin yapması zorunlu adımlar işaretli: **[HESAP SAHİBİ]**. Claude bu adımları yapamaz ve yetki uydurmaz.

1. **[HESAP SAHİBİ]** Google hesabı ile youtube.com → profil → "Create a channel" → **Use a custom name** → ad: `Plotted Past` (müsait değilse `channel/brand.md` alternatifleri).
2. Handle: `@plottedpast` (müsait değilse alternatif listeden). Handle müsaitliği bu ortamdan kontrol edilemedi.
3. Studio → Customization → **Branding**: profil `channel/assets/profile_800.png`, banner `channel/assets/banner_2560x1440.png`, watermark `channel/assets/watermark_150.png`.
4. **Basic info**: açıklama `channel/brand.md` → "Vaat"; dil English; ülke Türkiye (YPP Türkiye'de açık). Links: GitHub repo (isteğe bağlı).
5. **[HESAP SAHİBİ]** Settings → Channel → Feature eligibility: **2-Step Verification** aç; gelişmiş özellikler için telefon/kimlik doğrulaması (özel thumbnail, 15 dk+ video, zamanlama için gerekli).
6. Settings → Upload defaults: kitle "No, it's not made for kids"; dil English; kategori Education; lisans Standard; yorumlar "Hold potentially inappropriate comments for review".
7. Playlist'leri oluştur (`channel/brand.md` → Playlist yapısı).
8. **[HESAP SAHİBİ]** Earn sekmesi: eşiğe gelince "Apply" → AdSense bağlama (vergi/banka bilgileri, sözleşme). Bu adımlar yalnızca kanal sahibine aittir; proje bu bilgileri hiçbir yerde tutmaz.
9. İlk yükleme: `docs/operations/publishing.md` → B.
